Nguyên tắc bố cục

  • Sidebar 248px chia nhóm (Đang chạy · Game quà · Camera · Tương Tác 3D · Hiệu ứng & PK · Công cụ · Hệ thống), thu gọn 72px. Chấm xanh = game đang chạy — chỉ thứ đang chạy mới tô nổi.
  • Top bar 60px: ô @TikTok + Kết nối, trạng thái LIVE, số liệu, nút Bình luận / Quà lạ / Âm thanh / Ghim (thay 5 nút tròn cũ).
  • Header game chuẩn (mọi game giống nhau): icon · tên + trạng thái · mô tả · Bật · Link OBS ▾ · Chạy thử ▾ · Làm mới. Dưới là tab Cài đặt / Quà / Giao diện / Âm thanh.
  • Thân game 2 cột: trái = cài đặt dạng hàng (nhãn trái, điều khiển phải 260px); phải = xem trước overlay + hộp link OBS (dính khi cuộn).
  • Thanh lưu dính đáy khi có thay đổi. Ctrl K mở mọi game / cài đặt. Thanh trạng thái 34px dưới cùng.
  • Không đổi: id phần tử trong panel game, đường dẫn /overlay/*, CSS overlay OBS dùng chung (Hũ nạp /style.css).
