# Đập Muỗi — kế hoạch triển khai

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Game camera "Đập Muỗi" chạy trong 🎥 Game Camera: muỗi bay ngang phủ màn, streamer vỗ 2 tay giết muỗi, quà thả muỗi / xịt / vợt / mắc màn.

**Architecture:** Engine thuần (`game.js`) và bộ nhận diện vỗ tay (`clap.js`) là UMD không DOM, test bằng `node --test`. Overlay nhận hình camera OBS qua feed chung (`touchplay:feed`) + `HpTracker` trong trang, vẽ canvas 2D. Server đăng ký game con của Game Camera, phát quà qua socket `dapmuoi:gift` như Chém Trái Cây.

**Tech Stack:** Node 24 / Express / socket.io, MediaPipe Tasks (`public/lib/hp-tracking.mjs`), `public/lib/obs-scene-map.mjs`, canvas 2D, WebAudio, Electron `globalShortcut`.

**Spec:** `docs/superpowers/specs/2026-10-13-dapmuoi-design.md`

## Global Constraints

- Sân khấu 1080×1920 px, thời gian ms, y tăng xuống dưới; engine không đụng DOM.

- Route riêng dưới `/api/dapmuoi/*`; không thêm route trùng `/api/games/:id/state|config`.
- Panel chỉ GỬI config (không áp echo khi đang lưu); overlay là bên nhận.
- Tên hiển thị tiếng Việt có dấu; id game `dapmuoi`; CSS prefix `.dm-`.
- Commit nhỏ sau mỗi task trên nhánh `feature/dapmuoi`, kết thúc commit: `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
