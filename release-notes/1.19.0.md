  game). Combo ×N = N lần số giây; quà của game khác: chơi kế tiếp / xếp hàng / cắt ngang. Mặc định tắt, bật ở Game Camera.

  mọi game camera (cầu, muỗi, mũi tên, quả, game tách người…), không bỏ quà khi hàng dài.
- Chơi tối đa 4 game cùng lúc: 1 game dùng tay + 1 game trên đầu + Đá Cầu + game tách người.

  🛰 báo khi Scene đang phát thiếu overlay Game Camera + nút ＋ Thêm nhanh vào OBS.
